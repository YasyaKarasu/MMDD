# AbeBooks 小规模多模态 Joinability 数据集技术报告

日期：2026-10-01  
范围：现有数据集的问题、已完成修改的复盘，以及基于现有候选湖的最小修正方案。  
状态：本报告和配套统计已生成；报告中的后续方案尚未实施，未生成新数据版本或启动新训练。

## 1. 结论与路线选择

**原始数据仍有构造合理小规模数据集的可能。当前应修正任务定义、查询资格和连接标签，并保留原有候选湖规模。** 此前将数据重组为 52 张候选表的方案同时改变了检索难度和连接语义，不能作为正式数据集的最终方案。

本报告采用已确定的第一条路线：以现有表、图片、文本和批准恢复标注为基础，构造一个可审查的、受控的小规模多模态连接实验集。它的目标是检验“证据补充缺失属性后，是否形成正确且有用的连接”，不承担大规模自然数据湖或独立训练大型模型的定位。

建议以修改前的 **174 张候选表**作为固定候选集合，优先审核现有作者连接查询，修正多正例和误负例问题，补上属性恢复与实际连接的验证。减少不合格查询不应同时缩减候选湖，也不应通过重复组合相同行来制造样本规模。

更正式的“图书—销售记录—卖家”重构有原始数据基础，但不纳入这轮必要工作。首先把现有数据的任务有效性做清楚，再决定是否有必要增加投入。

## 2. 数据版本与统计口径

本报告区分三个层次：最初抓取的原始记录、修改前的实验数据集、出版社重组实验版本。“原版 174 表”专指下表第一行，不与历史上其他 160 表或 220 表实验混用。

| 版本 | 路径 | 源表 | 候选目标表 | 查询 | qrels 正例记录 |
|---|---|---:|---:|---:|---:|
| 修改前实验版本 | `dataset/abebooks_joinability_no4_disjoint_20260930` | 130 | 174 | 118 | 120 |
| 出版社分组并合并长尾版本 | `dataset/abebooks_publisher_partition_tail5_20260930_v2` | 46 | 52 | 70 | 70 |

修改前版本有 59 个 implicit 查询和 59 个 explicit 查询。一个查询可以有多个正例或连接属性，因此按属性统计的 qrels 数量不能直接相加解释为独立查询数量。

两版都保留 1,289 条源记录，即 1,158 条图书记录和 131 条卖家记录；多模态素材共有 5,441 个，其中 3,568 条文本、1,873 张图片。源表、候选表、查询、恢复证据记录分别属于不同计数单位。

2026-10-01 的结构统计已保存为 [STRUCTURAL_AUDIT.json](../work/abebooks_small_dataset_report_20261001/STRUCTURAL_AUDIT.json)。其中：

- “不同恢复事实”按属性内的源表、源行、属性值去重；同一行的多个证据不重复算成多行监督。
- “连接行对数”使用原始隐藏值做精确等值连接，是结构诊断，不是新预测的恢复结果，也不是已经审核正确的连接结果。
- “其他表覆盖至少两行”按其他 target ID 计数，包含不同投影视图；它用于发现潜在标签问题，不等于已确认的额外正例数量。

## 3. 当前主要问题

### 3.1 随机拆表和单出版社分表分别存在不同缺陷

原始图书表主要由打乱后的记录分块形成。出版社值在很多表里反复出现，单纯恢复出版社往往不能确定哪张表具有独特的连接价值。如果按“存在出版社值重叠”判断 joinability，多个候选表可能都应该是正例；只按共同来源指定目标会引入标签不完整问题。

出版社分组则走向另一种退化：同一出版社的行被集中到一张表，出版社变成整张表的类别标识。恢复一个出版社名称可以帮助定位对应分区，却不一定能建立有意义的行间关系。

新版本中，35 个 implicit 查询有 28 个以 `publisher` 为隐藏连接列，**这 28 个正例的目标连接列全部是常量**。测试集的 4 个 implicit 查询也全部属于此类。

### 3.2 唯一隐式检索命中没有建立有效连接

此前报告的测试案例 `query_984f49de20a20cde_source_9acac02ed161` 有 5 行，query 可见列为 `title`、`authors`；目标表为 `publication_year`、`publisher` 两列，共 42 行。双方出版社真值均为 `Morgan Kaufmann Publishers`。

如果全部正确恢复后只按出版社等值连接，将产生：

```text
5 个 query 行 × 42 个 target 行 = 210 个匹配行对
```

每本书都会连接到目标表的全部 42 行，无法据此判定这本书对应哪个出版年份。目标由 Direct 第 26 位上升到 RRF 第 8 位，是已发生的排序结果，但它不能证明补属性后得到了正确的图书属性对应关系。

常量列或多对多连接并非在所有任务中都不合法。例如，图书与真实出版社资料表可以形成有用的多对一关系。本例的问题是目标仍为书目记录，连接值被用作分表标签，缺少更细的对应关系。

### 3.3 现有构造条件偏重“属性可恢复”，没有充分检查“恢复后可有用地连接”

构造器会检查隐藏属性的批准恢复证据和 query/target 投影条件，随后生成 qrels。该过程不自动保证连接列具有足够区分度，也不保证连接结果能正确补充目标属性。

重建逻辑中，explicit 候选通过 `modal_share < 1.0` 排除了常量连接列；implicit 分支没有相应过滤。这使得常量出版社只要满足恢复证据条件，仍能获得 `model_recoverable_join_column` 标签。

因此必须分别审核两个命题：

1. 证据能否支持该行的隐藏属性值；
2. 使用这个值连接后，能否得到符合任务定义的记录或实体关系。

第一个命题成立，并不自动推出第二个命题成立。

### 3.4 候选湖缩小和查询变化混淆了检索改进

实际修改前实验版本有 174 张候选表；历史“原表自然作者名＋书目字段”实验为 160 张，未合并长尾的精确出版社分表实验为 220 张，最终长尾合并版本为 52 张。

这些版本的候选粒度、字段、查询和划分同时变化，不能把跨版本 Recall 改进归因于模型或某一种清洗规则。作为规模影响的示意，在单一正例、均匀随机排名的假设下，top-10 命中的期望从 `10/174≈5.75%` 变为 `10/52≈19.23%`。这不是实际模型基线，也不适用于所有多正例口径。

52 张候选还小于现有 D100/C150 设置，候选池可包含全部目标，因而无法用该配置证明证据发现了原本不在候选池的目标。

### 3.5 监督数量、数据质量和独立性都有边界

修改前版本的 168 条批准恢复记录主要集中在作者和出版社：

| 属性 | 恢复证据记录 | 不同源行及属性值 | 图片记录 | 文本记录 |
|---|---:|---:|---:|---:|
| authors | 58 | 43 | 47 | 11 |
| publisher | 106 | 82 | 85 | 21 |
| publication_year | 2 | 2 | 2 | 0 |
| region | 2 | 2 | 0 | 2 |

43 条作者事实有用，但不足以把大量五行 query 都标成“完整可恢复”。若要求五行都有证据且 query 不重复用行，仅从数量上看最多能组成 8 个完整 query，其他质量条件还可能进一步减少数量。

原始作者字段也不能视为无误真值：原始完整图书表中有 `-`、`0` 等占位字符串；书名和作者来自卖家声明，存在作者列表、省略和姓名格式问题。现有批准标注提供了支持证据，但仍需核对它支持的是单个作者、完整作者列表，还是只支持源字符串的一部分。

历史数据已经在多轮实验中暴露。重新划分不能把它恢复成未触碰的独立测试集。少量源组中的多个 query 也不能当作相互独立的大样本。

下表记录的是已完成的历史修改；“建议”是下一轮的处理方向，并非已经执行的回退。

| 已完成修改 | 实际结果或动机 | 后续建议 |
|---|---|---|
| 按原始出版社字符串精确分组 | 194 个组，不做出版社名称归一化 | 正式主实验撤回该分表依据，保留历史产物用于对照 |
| 将不足 5 行的出版社组合并 | 162 个组、230 行并为长尾表；形成 33 张图书源表，加 13 张卖家表 | 撤回该缩湖操作，回到现有 174 候选表集合 |
| 图书保留四列、卖家保留三列 | 图书为书名、作者、出版社、年份；卖家为名称、地区、描述 | 暂停全局字段重构，优先审核现有 query 的具体可见字段 |
| 恢复 `seller_name` | 从原始参考表恢复，以解决当时 35 implicit 对 32 explicit 的构造不平衡 | 恢复字段本身有依据，但不再为凑 1∶1 而扩展当前任务 |
| 作者姓名转自然顺序 | 710 个源单元格变化，如 `Sutter, Herb` → `Herb Sutter` | 可保留为保守匹配规范化；保留原值并审计碰撞、歧义 |

| 回放已有批准事实 | 168 条全部输入，100 条在新布局中可用，没有新标注 | 复用原始 168 条作为证据起点，保留未使用项及原因 |
| 保留源记录和多模态素材 | 1,289 行各保留一次，5,441 个素材内容和路径不变 | 继续保留，不按模型得分筛选素材 |
| 更新 ID、来源映射和缓存命名空间 | 避免对变化后的表使用旧特征 | 新版本仍需明确 lineage；表输入变化后重新编码 |

少于 5 行的合并阈值是此次源表布局的实验选择，不是原构造器已有的五行源表最低要求。

此次没有修改模型、损失、检索、融合及 checkpoint 选择规则；历史审计中 41 个核心方法文件与锁定哈希一致。相关检查包括 1,289 行保留、5,025 个保留单元格核验、原输入与备份一致性、1,400 个 Recall 值复算，以及 29 个相关测试通过。这些检查证明实现和记录的一致性，不能替代任务语义有效性的审核。

失败实验中的作者分组、书名语义分组、图书证据文本添加书名前缀等方案未进入最终 52 表版本。尤其不能把“全部素材保留”与“给素材补过书名前缀”混为一谈。

### 4.1 已完成实验应如何解释

| 52 表版本的 test 排序 | 总 Recall@10 | implicit Recall@10 |
|---|---:|---:|
| Direct | 2/7 | 0/4 |
| Selected KD Student Multimodal_RRF | 3/7 | 1/4 |

这些数字保留为历史结果。现在对其解释需要收紧：唯一 implicit 命中属于常量出版社连接，因此不接受为有效 joinability 改进的主要证据。新版本应以实际连接质量为验收条件，不能只要求达到旧的 Recall 门槛。

训练阶段虽已执行，C1/C2 的最终选择均落在初始化，不能宣称学生训练或 KD 带来了收益。此前也未重新执行属性生成与最终 join 验证；“旧证据被保留”“目标进入 top-10”“属性被正确恢复”“连接结果正确”必须分别报告。

历史报告中“达标”指当时的检索数值门槛；本报告对数据集有效性的判断优先于将该版本视为正式成果的表述。历史产物保留以便复盘。

## 5. 第一条路线的可行性依据

### 5.1 作者连接提供了可审核的非退化起点

对修改前版本做原始隐藏值等值连接诊断，结果如下：

| 诊断项 | authors | publisher |
|---|---:|---:|
| 对应 implicit qrels | 21 | 38 |
| 常量目标连接列 | 0 | 0 |
| query 的不同非空连接值数量 | 20 个为 5，1 个为 4 | 3–5 |
| 完整原值等值连接的匹配行对数 | 20 个为 5，1 个为 4 | 5–17 |
| 其他 target 至少覆盖两行的数量，最小/中位/最大 | 0 / 0 / 2 | 10 / 64.5 / 99 |

这些结果说明作者连接不需要通过缩小数据湖或按答案值分组来获得区分度。但 21 个查询只是审核候选，尚不能宣布全部合格。匹配行对较少只是有利条件，同名作者、同一作者多本书、部分作者列表匹配仍可能导致语义错误。

原始来源 ID 可以帮助核对书籍与源记录对应，但不能直接作为模型输入，也不能把“来自同一源行”自动等同于“按当前连接列执行连接即可恢复该源行”。

### 5.2 小规模定位允许少量高质量查询配较完整的候选湖

一个合理的 pilot 可以有几十个或更少的已审查 query，同时保留 174 张候选表。query 的质量门槛、候选湖规模和模型训练样本量是三个不同问题。

若审查后只有少量作者 query 合格，应如实定位为机制验证集，并逐例报告结果。不能为了凑齐 train/dev/test 或 1∶1 类型比例，放宽语义条件、重复同一证据，或把原本明确相关的表删掉。

“小规模”允许统计能力有限，但不允许正例本身是退化连接、潜在正例被当作负例，或把同一本书的多个视图当成独立泛化证据。

### 5.3 正式重构可延后

原始抓取文件中，1,158 条成功图书抓取记录包含 12,556 条不同 listing ID 的销售卡片，说明数据并非没有关系结构。它们尚未全部核验为同一版本、也未全部建立可恢复属性标注，因此不把它们计入本轮有效样本规模。

考虑时间约束，本轮无需恢复全部销售卡片、建立卖家目录或重做实体层。现有证据审核和标签修正已足够形成一项独立、可交付的工作。

## 6. 建议的数据修正方案

### 6.1 固定原候选湖，先修改任务视图和标签

以 `abebooks_joinability_no4_disjoint_20260930` 为基础新建版本。首轮固定其 174 个 target 的身份、来源及行列内容，不合并源表，不按出版社或作者值重新分区，不因 query 被排除而删除其目标表。

优先新增 query 资格、连接语义、标注状态和排除原因记录；对确定的可见值泄漏，可以按统一规则产生经过遮蔽的 query 视图。匹配规范化先作为独立层记录，避免将表结构变化、编码文本变化和标签修正同时混入第一次比较。确需规范化编码输入时，另存版本并对所有方法使用同一输入。

保留 174 表是本轮预先固定的设计条件，不是质量豁免。如果审核发现无法解析或错误的候选表，应记录原因并修正；不能为了保持数字而保留无效表，也不能为提高 Recall 删除困难候选。

### 6.2 先审核作者，再决定其他列是否进入主任务

首批审核现有 21 个作者 implicit 查询及其 43 个不同源行事实。建议逐项检查：

1. **值有效性**：空值、占位符、无法解释的作者串不能参与连接；保留原字符串与规范化结果的映射。
2. **非退化性**：主任务排除只有单一有效值的 query/target 连接列；同时记录值频次和每行匹配数，不以“非恒定”作为充分条件。
3. **连接语义**：明确目标是同一本书的属性补充，还是同一作者的书目关联。前者不能靠作者相等直接判定实体相同；后者不能报告成同一本书属性恢复。
4. **证据支持**：至少沿用现有两行批准证据的构造起点，但逐行核对。该数量条件只是最低筛查，不能替代任务审核。
5. **信息遮蔽**：检查实际编码输入中的书名、上下文、caption、元数据和资产路径，避免隐藏作者仍直接暴露；用于评测的原值和来源 ID 不进入模型输入。
6. **增补价值**：至少能明确指出 target 提供了哪项 query 缺失的信息，并说明该信息通过何种关系归属于 query 行或实体组。

仅部分行有证据时，标为“部分恢复可验证”，按已判定行报告恢复和连接指标，不将未审核行视为错误或正确。五行全部可验证的子集可以单独报告，但不强求通过新造组合扩大它。

`publisher`、`publication_year`、`region` 暂不作为首批主任务的默认合格连接列。保留原数据和历史标签，审核后分别纳入辅助任务、直接连接任务或排除清单。品相、装帧、评分等低基数字段也不因为能被恢复就自动成为合格连接列。

对于作者无法支持同一本书对应关系的样本，优先排除或转入明确的作者关联诊断集；首轮不为挽救这些样本追加复杂复合键构造。

### 6.3 修正全候选湖上的正例与负例

对每个保留 query，在完整候选湖中枚举连接值重叠，结合字段含义和来源记录复核。重叠扫描负责提出待检查对象，不负责自动赋予正例。

审核输出采用“已确认正例、已确认负例、未判定”三种状态。多个表满足同一连接任务时都应记录为正例；共享源表只是来源线索，不是独占正例的理由。同理，相同出版社或相同作者字符串也不自动构成正确的图书属性连接。

训练和蒸馏中的负采样、路径监督、证据标签与评测 qrels 必须使用一致的正例集合。未判定候选不能静默作为可靠负例。

对于进入主评测的少量 query，优先完成全湖潜在匹配的审核，使正例集合尽量完整；如仍有未判定目标，需明确报告 judged coverage，不能把不完整 qrels 的 Recall 当成完备真值指标。

### 6.4 采用保守清洗，避免再次扩大实验变量

保留无歧义作者姓名顺序规范化、占位符识别和隐藏值泄漏检查。作者列表的拆分、姓名别名归并和模糊匹配需要单独审核，不能仅因字符串相近就合并作者。

本轮暂不全局精简字段、不恢复新销售记录、不追加文本书名前缀、不按标注筛掉其余素材。字段是否遮蔽根据任务泄漏和连接语义决定，而非按验证集得分选择。

所有修改以新版本保存，保留原始值、原始 query/target ID、恢复标注来源和排除原因。不要覆盖历史数据与实验记录。

### 6.5 划分与小样本报告

优先保留已有源组边界，并检查同一图书实体、相同行、相同或高度重复的证据是否跨划分。已有源组互斥不自动等于实体或证据互斥；新增作者规范化也可能揭示原先未识别的重复。

首轮沿用原划分并报告审核后各 split 的真实数量。若 dev/test 只剩极少样本，明确作为描述性回归结果。需要重新划分时，另建版本、按源组或实体组预先固定，不能按方法得分分配样本，也不能称其为未暴露测试集。

不强制 implicit/explicit 数量相等；两类分开报告，说明数量与连接属性分布。若保留全部类型的总体指标，还应披露构成变化，避免总体提升仅来自任务比例变化。

## 7. 最小验证闭环与优化顺序

先验证任务本身是否有效，再优化检索。建议使用同一 query、同一候选湖和同一标签执行以下对照：

| 条件 | 用途 | 解释边界 |
|---|---|---|
| Direct，仅可见表格 | 测量可见上下文已经能完成多少连接 | Direct 成功的样本不应被描述为必须依赖证据 |
| 原始隐藏值补回后执行连接 | 检验选定连接列是否足以建立预期关系 | Oracle 诊断，不能当作模型恢复结果 |
| 已批准正确证据输入属性恢复器 | 区分恢复能力问题与证据检索问题 | 使用证据真值的上界诊断，不是端到端结果 |
| 实际检索证据 → 恢复属性 → 连接验证 | 测量完整机制 | 同时报告证据、恢复、行对和表级结果 |
| 移除或交换证据 | 检查正确证据是否产生贡献 | 使用固定策略，检查交换后是否仍意外包含答案 |

如果原值补回后仍不能建立正确关系，应修正或排除样本，不继续靠训练提高该样本的召回。如果正确证据输入仍无法恢复，再检查规范化、作者列表和恢复模型；若正确证据能够恢复而检索证据不行，才把优化重点放在证据召回与聚合。

最小闭环可以直接验证规范化后的等值连接，不必先重做完整的二阶段大模型 verifier。前提是任务定义已经限定为这种连接，歧义样本经过审核，且原值、模型预测值和来源 ID 的用途严格区分。

### 7.1 建议报告的指标

| 层次 | 最小报告内容 |
|---|---|
| 数据结构 | 固定候选表数、独立源组数、有效 query 数、不同证据事实数、正例数分布 |
| 表级检索 | 沿用并明确 Recall@k 定义；多正例时同时区分 Hit@k，分 implicit/explicit 和属性报告 |
| 证据覆盖 | 已批准行/属性事实中，检索到支持证据的数量与比例；没有批准标注的证据保持未判定 |
| 属性恢复 | 已判定行上的正确值恢复数、错误数、拒答数和覆盖率；部分作者列表单列 |
| 实际连接 | 已判定正确行对的 precision/recall、query 行覆盖率、每行匹配数量及错误扩张 |
| 机制贡献 | 同一 query 下，正确证据相对 Direct、无证据、交换证据的配对差异 |
| 成本 | 恢复调用数、推理耗时；若训练则披露实际样本量和 checkpoint 选择 |

多正例下，`Recall@k = |TopK ∩ Gold| / |Gold|`，`Hit@k = 1[TopK ∩ Gold 非空]`。历史指标保留原口径；新报告不能将二者混称。如果真值未覆盖所有潜在行对，就只报告已判定范围的结果和覆盖范围，不计算貌似完整的行级 precision/recall。

小样本首先报告命中分子、分母及逐例结果。若使用区间或重采样，应以源组或实体组为单位，避免把同一来源的多个 query 视为独立重复。

### 7.2 时间受限时的实施优先级

| 优先级 | 工作 | 交付物与通过条件 |
|---|---|---|
| P0：必须 | 固定原 174 表；审核 21 个作者 query；检查常量、歧义、泄漏与增补价值 | 逐 query 审核表、排除原因、有效连接定义；样本数由审核决定 |
| P0：必须 | 对保留 query 扫描全候选湖，补全正例并标记未知 | 可追溯 qrels、行对依据、负采样禁用清单；未知不被当作可靠负例 |
| P0：必须 | 执行原值补回的连接诊断，审查实体和证据跨 split 重复 | 证明样本的连接列本身可用，披露剩余独立组数 |
| P1：主实验 | 固定模型配置，比较 Direct、正确证据、实际检索证据及证据对照 | 至少完成部分行上的真实属性恢复与正确连接闭环 |
| P2：有余力再做 | 在现有素材中补充审核作者证据，覆盖更多独立源组 | 新增可验证事实，不以复制视图增加表面规模 |
| 延后 | 全销售卡片、卖家目录、完整实体层重构；大范围训练与参数搜索 | 不作为本轮报告和小规模数据集交付的依赖 |

主实验先固定现有模型与检索参数，避免边修数据边选择融合参数。标签、query 或目标输入变化后，旧训练权重和旧缓存是否还能用于公平比较需要单独说明；若进行新训练，应使用修正后的监督并重新编码变化后的表。固定模型的诊断结果不能包装成新的训练收益。

## 8. 验收条件与可支持的结论

本轮数据集的完成条件应是：候选湖身份与规模有记录；保留 query 的连接任务可解释；有已核验证据和行级对应依据；潜在多正例得到处理；不使用常量类别分表作为主连接任务；实际验证了属性恢复后的连接；所有未判定项、排除项和小样本限制可追溯。

不设置必须达到旧的 `Recall@10 ≥ 0.40` 或 implicit `≥ 0.10` 才算数据有效。正确数据上的负结果仍有研究价值；通过改变候选规模或连接定义达到数值门槛不能替代验收。

如果后续结果成立，可支持的表述是：

> 在由现有 AbeBooks 记录构造、候选湖固定的受控小规模任务中，针对经过审核的缺失属性，多模态证据能否改善值恢复，并形成可验证的连接关系。

本轮不能预先支持：任意真实数据湖上的稳定泛化、作者字符串普遍唯一标识书籍、出版社恢复普遍解决书目连接、KD 必然产生收益，或仅靠 top-k 命中就完成 joinability discovery。

若有效 query 太少，交付一个带完整证据与连接审核的小型案例集；若部分来源不具备有意义的连接，则保留为失败或排除记录。有限规模应作为研究范围说明，而不以退化样本补足数量。
