Stage-1 优化 · R1–R6 复盘

六轮实验的一条主线：
训练为什么在破坏检索，以及怎么修

全部六轮可以串成一个问题的逐层归因：为什么在冻结 embedding 上做训练，反而让检索变差。 每一轮的动机都是上一轮的结论。这份复盘只保留这条主线上的实验，旁支消融省略。

时间 2026-08-28 → 08-31 数据湖 EntiTables · WDC 口径 recall@{10…50} · γ=10 · 配对 bootstrap CI 当前 R7 进行中

起点：一个反直觉的观察

系统是两通道检索：direct(Q→T) 与 evidence(Q→E→T 一跳路径)， 底座是冻结的 Qwen3-VL-Embedding 4096 维向量，Student 学的是每个 type-pair 的关系矩阵 R。

冻结底座本身很强：mixed dev 上 raw direct R@10 = 36.84%。零训练的 PCA-1024 投影几乎不掉点 (35.26%,raw 的 95.7%),说明降维不是瓶颈。但只要开始训练,identity-4096 初始化的 Student 在 epoch 1 就掉到 direct 14.3%,并逐 epoch 继续变差。

起点判断

训练目标(2–5 候选的窄列表 CE + 蒸馏一个过拟合 Teacher)的梯度方向,与"保持全局近邻结构"相互对抗。 后面六轮都在追这一件事的责任归属。

08-28 · 责任归属

破坏源在哪:是正则不够,还是 Teacher 有毒?

动机

两个候选假设:(A) 可训空间太大而监督太窄,加正则约束住就行;(B) 蒸馏目标本身有毒。 先补一个基础设施——epoch-0 评测,否则无法判断训练是在改善还是破坏。

做了什么

  • 插桩 epoch-0 基准 + 分数据集指标,验收线定为"任何 epoch 不得低于 epoch-0"
  • 冻结投影 P、只训 R,锚定正则 μ‖R−I‖²_F 扫 {0, 0.01, 0.1, 1.0}
  • KD 归因消融:同配置下 KD=1 vs KD=0
  • Teacher-as-reranker 诊断(零训练):直接测 Teacher 在检索口径上的价值

结论

同时发现 → 引出 R2

用检索对齐负样本重训 Teacher 后,重排 overall 到 40.18% (+3.25),且与 raw 的 per-query Spearman ≈ 0.015(近似正交的独立信号);但 WDC −13.9pt、E→T 27.65% 低于 raw 33.13%。 Teacher 有真信号但严重偏科,单独用不行 → 试组合用。

08-29 · 健康基座上重测

在修好的基座上重测 anchor,发现一条单一 trade-off 曲线

动机

R1 的 anchor 结论作废,必须在健康配方(fresh PCA-1024 + 冻结 P + 跳过 student-edge + path-only + KD=0 + in-batch)上重测。同时 R1 暴露另一个贯穿性症状:所有训练都让 WDC 回退 (raw 61.88% → 最优 student 54.46%),而 overall 被 938/1140 的 EntiTables 权重稀释,gate 看不见。

做了什么

  • 真正的 anchor × dataset-α sweep,并把每个 type-pair 的 ‖R−I‖_F 逐 epoch 落盘(relation_drift)
  • checkpoint gate 改为分数据集约束,不再只看 overall
  • Teacher z-score ensemble:重排分 = α·z(s_T) + (1−α)·z(cos),α 扫 {0.3…0.7}
  • 按数据集门控的 KD 消融(EntiTables 权重 0.3 / WDC 0)

核心结论:trade-off 是结构性的

训练沿同一条曲线移动:‖R−I‖ 每增加,EntiTables 单调涨、WDC 以约两倍幅度跌。 anchor 只能减速、不能改方向;dataset-α 无关(过采样假设排除)。在 WDC gate 下唯一合规的选择是 epoch-0,即不训练。

另一半:ensemble 成立

因为 Teacher 与 raw 近似正交,组合使用两者互补——raw 兜住 WDC 与 MRR,Teacher 贡献 EntiTables 的语义增益。 α=0.7 时 overall 47.37%(raw 36.93%,+10.7pt)、WDC 64.85% ≥ raw、E→T 43.69%(raw 33.13%)。 在线架构由此确立为两级:student ANN 召回 → teacher-ensemble 重排。

引出 R3

KD(蒸 teacher logits、按数据集门控)全 epoch 在 WDC gate 失败,KD 方向存疑。同时注意到 WDC dev 只有 202 查询、每查询 1 个正例 → 1pt = 2 条查询,历次 "gate fail" 可能只是噪声。 gate 判据本身需要统计化。

08-29 · 评测口径与统计判据

把口径和判据修对,然后 KD 交出真实轨迹

动机

三个都会影响结论可信度的问题:(1) 评测用 recall@100/mrr@100,不是领域惯例口径; (2) 检索预算 direct_k=100 等是写死的绝对常量,论文里是无法辩护的死参数; (3) WDC gate 工作在噪声量级(R2 结论)。

做了什么

  • 口径切到 recall@{10,20,30,40,50} + mrr@50,对齐 joinability discovery 惯例
  • 检索预算改为 k 驱动:direct = γ·k、evidence = γ_e·k,γ 用敏感性曲线辩护;每个被测 k 独立跑
  • gate 改为配对 bootstrap 95% CI(10,000 次, seed 13, tolerance −0.02),替代裸点估计
  • 四基线重建 + γ/γ_e 扫描 + ensemble-KD 两组剂量

Task H 的真实读法 → 引出 R4

ensemble-KD 两组权重都在 WDC CI gate 失败,但把轨迹摊开看:KD=0.3 让 EntiTables 从 29.74% 涨到 ep8 的 35.39% (+5.65pt,项目至今最大训练增益),而 WDC 同步沿老曲线从 60.4% 掉到 48%。 失败的不是蒸馏信号,是"单个共享 R 同时服务两个机制不同的数据湖"这个前提。

08-29/30 · 转折点

按湖实例化:训练增益第一次真正拿到

动机(一)· 这条曲线本身

R2/R3 反复观察到的同一现象,画出来就是一把剪刀。两条线是同一次训练里的两个湖: 梯度让一个湖单调涨,同时让另一个湖单调跌。

动机(二)· 领域惯例查证

查了 Snoopy (TKDE'25) 与 LakeBench (PVLDB'24):两篇都按数据湖分别训练、分湖建索引、分湖报离线成本, 没有任何一篇跨湖联合训练。我们把 EntiTables + WDC 合并成 27.9 万对象的混合语料, 导致 EntiTables 查询会检回 WDC 表作干扰项——既不符合惯例,也不符合部署现实。

做了什么

  • 语料/PCA/索引/训练列表全部按湖拆分(校验两湖 ID 精确互斥且并集等于混合语料)
  • gate 改为湖级独立;每湖重建四条基线
  • 分湖训练 + 蒸馏 ablation(EntiTables 3 组 / WDC 2 组),再按需重训分湖 Teacher(Task M)
  • 结果反常后追加一次独立只读审计(五项)

审计结论 + 新悖论 → 引出 R5

08-30 · 机制归因

蒸馏增益到底来自哪:Teacher 的知识,还是 cos 的锚定?

动机

回答 R4 留下的悖论。可检验的假设:蒸馏目标是 τ·z(s_T) + (1−τ)·z(cos), 其中的 cos 锚 + 低容量 student + 锚定正则把 Teacher 的错误结构性过滤掉了—— Teacher 提供的更多是"让训练变稳"的锚,而非可迁移知识。做法很直接:把 τ 扫开。

做了什么

  • τ ∈ {0, 0.3, 0.7, 1.0} 逐湖归因消融(τ=0 即纯 cosine 目标,完全不含 Teacher)
  • 用混合负样本重训 WDC Teacher,检验"湖内负样本多样性不足"假设
  • evidence-binding / modality-balance 消融(image 关系在 WDC 极度稀疏:149 条 vs text 4,680 条)

结论:两个湖的答案不同,悖论解开

EntiTables:τ 单调升到 1.0 → Teacher 知识确实可迁移,线上重排也全程正向 (+15.25pt)。 WDC:τ 曲线非单调(0.7 处见顶,1.0 回落)→ Teacher 有知识但噪声大,0.7 是判别力与噪声的平衡点; τ=0.7 相对纯 cos 的 "Teacher 残差" = +2.48pt [0.00, 4.95],是真实独立贡献。

悖论的答案:蒸馏能挑出 Teacher 的部分知识而把噪声滤掉,在线重排则要为噪声全额付费。 直接证据是 WDC 纯监督恒回退到 epoch-0,而带蒸馏目标能训到 epoch 5 并转正——这正是"锚定作用"。

同轮否定 + 引出 R6

混合负样本重训 WDC Teacher 更差(−29.70% vs −23.27%),排除多样性假设, WDC 线上重排定性为 no-op / 负资产(诚实负结果,不再投入)。 另一头,evidence 通道仍然很弱(EntiTables evidence R@10 仅 4.05%、coverage 3.41%), 而且只能靠把 evidence_weight 硬压到 0.05 才不伤 fused ——怀疑分数尺度错配。

08-30/31 · evidence 通道与合成教训

尺度假设被证伪,但归一化仍然有效——原因不同

动机

evidence 路径分数 = s(Q,E) + s(E,T),两段走独立学习的关系矩阵、各有独立尺度。 训练后 R 漂移(EntiTables ‖R−I‖ 达 3),若两侧幅值被拉开,则 (a) 路径聚合被幅值大的一侧主导、 (b) RRF 只按 rank 丢弃幅值 → evidence 分数不可信。若假设成立,归一化是零训练的根治。

做了什么

  • 先做零成本的每关系分数尺度诊断(先证伪再动手,避免在错问题上白忙)
  • 融合方案:RRF vs 归一化分数加权(z-score / min-max)
  • 路径聚合变体:logsumexp / topk_sum × 每边归一化开关
  • τ 自适应启发式(免调参);保留 image 的模态平衡;表表示增强 F1/F2

结论(一):假设错了,但改动对了

尺度错配被证伪——student 各 type-pair 的分数统计与 raw 几乎一致,无 >2× 失配(μ=0.1 的 anchor 已经把尺度漂移压住了)。 然而归一化融合确实有效:WDC 65.35% vs RRF 64.36%。 所以收益的机制是"利用了幅值信息",不是"修正了尺度"——论文表述必须按此修正。

结论(二):本轮最重要的方法论教训

组件贪心选择 ≠ 联合最优。fusion / 聚合 / relation-weight / τ 各自单独为正, 合成后相对 r5 却是 EntiTables 0.00、WDC −1.49。 根因:Task E 用 "evidence 优先" 规则选了 relation weight 2,牺牲了 WDC fused(64.36 → 62.38), 而各组件从未做联合验证。

一句话串起来的主线

训练破坏检索几何 → 责任在 KD 而非正则(R1) → 在健康基座上重测,发现两湖单一 trade-off 曲线, 同时 Teacher 正交信号支撑两级架构(R2) → 修口径与统计判据,KD 交出"蒸馏有效、共享模型不行"的真实轨迹(R3) → 按湖实例化解除约束,训练增益首次成立(R4) → τ 归因说明蒸馏的作用主要是锚定而非知识搬运, 并解释"重排弱但蒸馏增"(R5) → evidence 通道靠归一化利用幅值改善,但暴露贪心 ≠ 联合最优(R6) → 关系参数化的方向约束(低秩残差)正在验证(R7)。

方法论上有三条反复起作用的纪律:epoch-0 基准(否则分不清改善与破坏)、 分湖 / 分数据集 gate(否则大数据集权重会稀释掉小数据集的回退)、 同候选池 + 配对 CI(否则 202 条查询上的 1pt 波动会被读成结论)。

明天可以讨论的几个点

都是从现有结果里直接长出来的开放问题,不是新提案。

  1. 召回深度瓶颈怎么写γ=10 时 R@50 仍未饱和,是已记录的瓶颈。是继续加深召回池,还是承认它并把它写成 two-stage 的固有取舍?
  2. WDC 的统计功效202 查询、每查询 1 正例,1pt = 2 条查询。所有 WDC 结论的 CI 都很宽(如 +1.98 [−0.50, +4.95])。是否需要扩 dev 集才能支撑论文级断言?
